# Smoke-сценарии UI (сервис анализа GitHub-репозитория)

Запуск сервера: `"week 7/day 5/venv/bin/python" "week 8/day 3/smoke/smoke_server.py"` → http://127.0.0.1:5012
(офлайн-заглушки: GitHub/DeepSeek/Telegram не нужны). Перед каждым сценарием — чистое состояние:
открыть страницу, выполнить `localStorage.clear()`, перезагрузить.

На КАЖДОМ шаге: (1) выполнить действие, (2) проверить ожидаемый результат по DOM (`#status`, `#out`, `#title-h`,
`#pub`), (3) сделать скриншот `window.__shot("<id>_<шаг>")` и нативный скриншот для визуальной проверки.

## S1 — Валидация пустой формы
1. Открыть `/`. Ожидание: заголовок `🐓 Rooster GitHub-репозитория`, `#pub` disabled, в `#out` «Результат появится здесь…».
2. Нажать «Анализировать» с пустым репозиторием. Ожидание: `#status` = «Укажите репозиторий» (класс `err`).
3. Ввести репозиторий `octo/demo`, ключ DeepSeek пуст, нажать «Анализировать». Ожидание: `#status` = «Укажите ключ DeepSeek (⚙ Токены)», блок «⚙ Токены» раскрылся (`#tokens.open`).

## S2 — Успешный анализ (happy path)
1. Раскрыть «⚙ Токены», ввести ключ DeepSeek `test-key`.
2. Репозиторий `https://github.com/octo/demo`, «Коммитов» = 3, снять галочку «rooster». Ожидание: заголовок `📰 AI-анализ GitHub-репозитория`.
3. Нажать «Анализировать». Ожидание: `#status` = «Готово · octo/demo · коммитов: 3» (класс `ok`); в `#out` отрендерены `h1` «Дайджест изменений octo/demo» и три `h2` (🔎 Главное, ✨ Новое, 🐞 Исправления); список `li` ≥ 3; `#pub` enabled.

## S3 — Ошибка: репозиторий не найден и ошибка AI
1. Ключ `test-key`, репозиторий `ghost/none`, «Анализировать». Ожидание: `#status` содержит «Репозиторий ghost/none не найден» (класс `err`), `#out` без результата, кнопка «Анализировать» снова enabled.
2. Репозиторий `octo/demo`, ключ `bad-key`. Ожидание: `#status` начинается с «AI:» и содержит «401» (класс `err`).

## S4 — Публикация в Telegram
1. Выполнить S2 (результат есть, `#pub` enabled).
2. Нажать «Опубликовать в Telegram» без токенов. Ожидание: `#status` = «Укажите Telegram токен и chat_id (⚙ Токены)», блок токенов раскрыт.
3. Ввести токен `tg-token` и chat_id `-100123`, нажать «Опубликовать». Ожидание: `#status` = «✓ Опубликовано в Telegram» (класс `ok`).

## S5 — Токены переживают перезагрузку
1. Ввести в «⚙ Токены» ключ DeepSeek `persist-key` и GitHub-токен `gh-token`.
2. Перезагрузить страницу (F5/navigate). Ожидание: поля `#deepseek_key`, `#github_token` содержат введённые значения (localStorage).
3. Выполнить `localStorage.clear()` и перезагрузить. Ожидание: поля пусты.

## S6 — Кнопка «📊 Статистика» (`#stats-btn`, блок `#stats-box`)
1. Открыть `/`. Ожидание: кнопка `#stats-btn` «📊 Статистика» enabled, `#stats-box` скрыт (`hidden`). Нажать её с пустым репозиторием. Ожидание: `#status` = «Укажите репозиторий» (класс `err`), `#stats-box` по-прежнему скрыт.
2. Репозиторий `https://github.com/octo/demo`, «Коммитов» = 3 (ключ DeepSeek НЕ нужен), нажать «📊 Статистика». Ожидание: `#status` = «Статистика · octo/demo · коммитов: 3» (класс `ok`); `#stats-box` виден; `#stats-authors` содержит `li` «Ann — 2» и «Bob — 1» (в этом порядке); `#stats-days` содержит «2026-10-20 — 1» и «2026-10-21 — 2»; `#stats-busiest` = «2026-10-21 (2)»; `#stats-btn` снова enabled; `#out` не изменился («Результат появится здесь…»).
3. Репозиторий `ghost/none`, нажать «📊 Статистика». Ожидание: `#status` содержит «Репозиторий ghost/none не найден» (класс `err`), `#stats-box` снова скрыт.
