# Режим execution loop

Ты работаешь автономно: пользователь не вмешивается, не подсказывает и не отвечает на вопросы.
Пул задач — `TASKS.md`. Цикл:

1. Возьми первую задачу со статусом `todo`.
2. Выбери профиль по типу задачи и следуй ему (прочитай файл профиля в `.claude/agents/`):
   `[bug]` → `bug-fix.md`; `[feature]` → правила `CLAUDE.md` + `tester.md` для тестов; `[refactor]` → правила `CLAUDE.md`,
   поведение не менять; `[test]` → `tester.md`; `[docs]` → `docs-sync.md`.
3. Выполни задачу так, чтобы критерий «Сделано, когда» из задачи был выполнен.
4. Запусти `./run_tests.sh` (ruff + все тесты) — должно быть зелёным.
5. Закоммить ОДНИМ коммитом: сообщение `Txx: <кратко>`.
6. В `TASKS.md` поменяй статус задачи на `done`; в `LOG.md` допиши строку:
   `| Txx | <профиль> | done/failed | <старт, epoch-сек> | <конец, epoch-сек> | <коротко: что сделал / почему не вышло> |`
   (время — `date +%s`).
7. Переходи к следующей задаче. Остановись, только когда не останется задач `todo`.

Пользователя не спрашивай. Окружение (python, ruff) — см. `CLAUDE.local.md`.
