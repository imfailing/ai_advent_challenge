# Week 9 / Day 3 — границы файнтюнинга

Что тюн чинит, а что ломает: добавляет ли знания, что теряет вне домена, как выглядит переобучение, на каких типах
задач выигрывает у промпта. Итоги и таблицы — [REPORT.md](REPORT.md).

| Файл | Что |
|---|---|
| `facts.py` | 40 выдуманных фактов (5 типов × 8), вопросы для обучения, перефразировки и обратные → `data/facts*` |
| `train_lora.py` | универсальное LoRA-обучение (аргументы: данные, эпохи, lr, чекпоинты) |
| `eval_knowledge.py` | знания: база / база+факты в промпте / тюн / тюн+факты |
| `ood_tasks.py`, `eval_ood.py` | 40 задач вне домена (QA, математика, код, перевод, формат, отказы, извлечение) |
| `scoring.py` | чистые автопроверки ответов (regex, JSON, запуск кода, отказ…) без torch |
| `eval_overfit.py`, `data/unlike.jsonl` | чекпоинты переобучения: eval дня 7 и «непохожие» запросы |
| `eval_style.py` | стиль: база / стилевой промпт / адаптер дня 6 |
| `common.py` | загрузка Qwen2.5-1.5B (с адаптером или без), жадная генерация |
| `test_day3.py` | офлайн-проверка наборов и автопроверок |
| `train.sh` | воспроизведение всего дня (на сервере с ROCm) |
| `out/`, `runs/` | результаты: ответы по каждому примеру, loss-логи, параметры запусков |

Адаптеры дня 8 в git не хранятся (лежат на сервере в `runs/`).

## Запуск

Локально (без GPU) — проверка наборов и автопроверок:

```bash
cd "week 9/day 3" && python facts.py && python test_day3.py
```

Обучение и eval — на машине с GPU, см. `train.sh`.
